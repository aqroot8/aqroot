## Why it is still a stop

Two failures, neither of them the corridor:

**The exact new first blocker (§17):** `BAT_PROTECTED_P R75.2 → D9.1` is rejected
at 1.50 mm on `copper_edge_clearance 0.5000 mm; actual 0.4125 mm` **and is never
retried at D-249's own 1.20 mm floor.** `run()` stops the width ladder the moment
`connect_role` returns ok, and the DRC gate runs *after* that — so a width that
routes geometrically but fails the gate is abandoned instead of falling to the
next rung. `PLAN_1_BPP_TRUNK` carries `[1.50, 1.20]` precisely for this, and the
1.20 rung needs R75.x ≥ 4.063, which the +0.75 window satisfies. **The rung that
would close the trunk is legal and simply never tried.** Recorded as **PR-49**;
not fixed mid-stop, because it changes router behaviour board-wide.

**Second:** the routed Kelvin detour. Analytic **7.378 / 7.267**; routed
**18.764 / 7.886**. That is a routing outcome, not a placement one — the
placement is inside spec by a wide margin — and it is the same class 002L saw at
4.948 mm, now much larger.
