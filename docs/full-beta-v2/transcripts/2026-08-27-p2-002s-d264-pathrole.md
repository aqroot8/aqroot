## 1. D-264 — outer-layer-only is scoped by path role (DELIVERED)

The 002R stop was caused by `BAT_MAIN is outer-layer only` applying to a whole net name
while its own justification is a 1.5 A / 10 K current-density calculation. D-264 scopes it
to the current path role, exactly as D-249 did for width.

`path_role_dru.outer_only_rules()` emits, per inner layer:

```
(rule "BAT_MAIN is outer-layer only - In2 - D-264"
	(layer "In2.Cu") (severity error) (constraint disallow track)
	(condition "A.hasNetclass('BAT_MAIN')
	            && !A.enclosedByArea('BAT_SENSE_KELVIN')
	            && !A.enclosedByArea('BAT_PROT_TAP_U18')"))
```

The two exempt areas are the **already-bounded, already-named D-249 sense corridors** and
nothing else. Current-carrying `BAT_MAIN` copper remains barred from In2/In3 everywhere.

**A defect found in the delivery, and it is a KiCad semantics fact worth recording:**
appending the scoped rule was not enough. KiCad's `disallow` constraint fires on **every**
matching rule, not last-match-wins, so the original unscoped rule stayed live and kept
rejecting the corridors. The generated board therefore has the static unscoped block
**excised** and the scoped pair written in its place. The authoritative `.kicad_dru` keeps
the unscoped rule so `dru_probe` still reads the shipped intent.

**Standing regression:** `d264_probe.py`, six clauses — **D-264 PROBE: PASS**

| clause | assertion | result |
|---|---|---|
| A | `BAT_MAIN` trunk copper on In2 outside the corridors | rejected |
| B | same on In3 | rejected |
| C | `BAT_SENSE_KELVIN` copper on In2 | allowed |
| D | `BAT_PROT_TAP_U18` copper on In2 | allowed |
| E | `BAT_MAIN` copper just outside a corridor boundary | rejected |
| F | no other rule class changed | confirmed |

## 2. Section 7 — `LTC_SHDN` was never a trapped pad

002R left `LTC_SHDN U18.6 -> R80.2` as `NO_LEGAL_ESCAPE` with an open board. Measured
alone, it is not trapped at all:

- **5 escape directions at 0.25 mm on B.Cu**
- via sites reachable at **0.60 / 0.50 / 0.35 / 0.25 mm**
- `U18.6 -> R80.2` routes **10.269 mm on B.Cu**
- `U18.6 -> Q4.3` routes **24.094 mm on B.Cu**

So the 002R failure was **neighbour copper laid earlier**, not geometry — which makes the
U18 pin-field *schedule* the real variable, and that is what section 8 tested.
